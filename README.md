# Bears-OS
This is a web os done under stardance hackclub challenge. 
# features
Bears OS has 4 apps. These are cave notes, calculator, gallery and an alarm. 
cave notes is a place where you put your own ideas. it has a space for note writing.
calculator has JS code backing it to work really well for integers. 
gallery has the image of bears which are the center of this OS.
the alarm functions as a place where we submit hours in and it calculates it for as.
# tech stack
it is all front end including html, css and java script.
# usage
once the website opens, a welcome window comes up. if it doesnt, make sure to click the bears OS sign at the top. 
the apps are interactive and there is a search button at the bottom to search for the apps youre looking for. 
it also has timer and date actively adjusted to your time line.
